# MindWorx Website — Copy Archive

Snapshot of the visible copy on every page of `mindworx-website` **before** the
repositioning work began. Captured so any phrasing, framing, or stat that gets
removed in the rewrite can still be recovered for review later.

This file mirrors the human-readable text only — HTML, CSS, scripts, icons,
and decorative markup are stripped out. Section headings inside each page are
preserved as sub-headings.

### The Stars

Eyebrow: **THE STARS**

Heading: **Those pieces are the stars.**

Lead:
> Every project scatters knowledge across tools, conversations, and people.
> Each fragment is a star — small on its own, powerful when connected.

Six "star" cards:
- **Specs & Requirements** — Requirements that define what needs to be built — often scattered across documents and versions.
- **Slack Conversations** — Decisions that happen in real-time but get buried under the velocity of daily communication.
- **Email Threads** — Concerns, approvals, and context that live in long threads only a few people ever read.
- **GitHub & Repos** — Naming conventions, patterns, and technical decisions embedded inside files and commit history.
- **Meeting Notes** — Dependencies, blockers, and context shared verbally — then roughly captured in notes nobody revisits.
- **Jira & Tickets** — Stakeholder assumptions and requirements hiding in comment threads inside issue trackers.
